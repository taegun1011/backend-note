## 트랜잭션 동기화
- 트랜잭션이 관리될 컨텍스트 (e.g. JDBC Connection)을 매번 새로 생성하지 않고, 최초 호출 시 생성 후 특수 저장소 (**ThreadLocal**)에 저장한다
- 이후 호출에서는 저장된 컨텍스트를 가져와 같은 트랜잭션 범위에서 작업을 수행한다
- 트랜잭션이 모두 종료되면 컨텍스트를 제거해 동기화를 마친다
- 스프링 지원
	- `TransactionSynchronizationManager`: 스프링이 제공하는 트랜잭션 동기화 관리 클래스
	- `JdbcTemplate`
		- auto commit 활성화: API 호출 시 자체적으로 커넥션을 생성하고 하나의 트랜잭션으로 동작
		- **트랜잭션 동기화 저장소에 컨텍스트가 있을 경우: 별도 기능 추가 없이 해당 커넥션 내부의 트랜잭션에서 동작**
- **동기화 단위는 스레드**
