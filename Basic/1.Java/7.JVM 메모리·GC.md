## 런타임 데이터 영역(Heap, Stack, Metaspace)
- heap
	- 객체가 생성되는 영역
	- 참조형 변수/상수를 통해 힙의 주소를 참조
- stack
	- 스택 프레임이 저장되는 영역
	- 스택 자료구조 형태로 변수가 생성되고 제거
- meta space
	- 메소드 영역이라고도 함
